# NGCD-DC

Самостоятельный эмулятор **Neo Geo CD для Sega Dreamcast**, версия 0.1.0.
Выделен из `dc-poker-ssrpg-r13`: в проекте остались только Neo Geo CD,
фронтенд Dreamcast, нужные CPU-ядра, конвертер дисков и диагностическая
сборка для ПК. Другие проекты для сборки не требуются.

Эмулятор использует настоящий BIOS Neo Geo CD и эмулирует 68000, Z80,
LC8951, CD-привод, DMA, LSPC и YM2610. Поддержка не ограничена Samurai
Spirits RPG, хотя именно эта игра была основной целью исходной версии.
Меню выбора игр пока нет: при запуске открывается один подготовленный
диск из `/cd/`.

## Возможности

- Dreamcast: FAME SH4 68000 и RAZE-SH4 Z80; сохранены исправления FAME из r13.
- PVR-отрисовка спрайтов, кэш 4096 текстур 16×16 и отдельный слой FIX.
  Автоматический переход на программную отрисовку при переполнении кэша
  или списка прямоугольников. Кнопка R переключает PVR/программный режим.
- Режим 320×240, изображение 320×224 без фильтрации и масштабирования.
- Два геймпада; backup RAM 8 КБ на первой VMU, файл `NGCDBAK`.
- YM2610 на 22050 Гц с интерполяцией до 44100 Гц; стереофоническая
  CD-музыка в IMA ADPCM, чтение отдельным потоком с буфером около 0,85 с.
- ПК-стенд на Musashi и superzazu Z80 с выгрузкой PPM-кадров и WAV.

## Сборка для Dreamcast

Нужны установленный KallistiOS, SH4 toolchain и настроенное окружение KOS.
Используются те же API KOS, что в исходном r13; точная минимальная версия
не установлена. Сборка выполняется из корня проекта:

```sh
source /opt/toolchains/dc/kos/environ.sh
make -j4
```

Результат — `ngcd-dc.elf`. Отладочная сборка печатает время эмуляции,
отрисовки, аудио, статистику PVR и нехватки аудиоданных.

```sh
make -j4 RELEASE=1          # тихая сборка без профилирования
make bin RELEASE=1         # также получить scrambled 1ST_READ.BIN
```

Объектные файлы debug/release разделены в `build/dc-debug` и
`build/dc-release`, поэтому между этими двумя режимами `make clean` не нужен.
При изменении toolchain или `EXTRA_CFLAGS` сначала выполните `make clean`.
Цель `make release` эквивалентна `make RELEASE=1`.

Для `make bin` нужен собранный `KOS_BASE/utils/scramble/scramble`.
Другой путь можно передать как `SCRAMBLE=/path/to/scramble`.
`1ST_READ.BIN` — загрузочный исполняемый файл, **не готовый CDI-образ**.

## Подготовка диска Neo Geo CD

Вход конвертера: CUE + BIN с дорожкой данных `MODE1/2352` и аудиодорожками
`AUDIO`; один общий BIN или отдельные BIN для дорожек.

Linux / другое окружение с C-компилятором:

```sh
make tools
./tools/ngcdconv/ngcdconv "/path/to/Game.cue" disc
```

Windows PowerShell — готовый x86-64 конвертер перенесён из r13:

```powershell
.\tools\ngcdconv\ngcdconv.exe "D:\NeoGeoCD\Game.cue" disc
```

Для пересборки Windows-конвертера через MinGW-w64:

```sh
make -C tools/ngcdconv windows
```

Конвертер создаёт `TOC.BIN`, `DATA.ISO` и `TRKnn.NGA`. NGA — сжатие
с потерями IMA ADPCM; блоки независимы, один блок на сектор CD.
Форматы файлов полностью совместимы с r13: уже подготовленные диски
повторно конвертировать не требуется.

В корне файловой системы будущего загрузочного диска Dreamcast разместите:

| Файл | Назначение |
| --- | --- |
| `1ST_READ.BIN` | Результат `make bin RELEASE=1` |
| `NEOCD.BIN` | BIOS CDZ, 512 КБ; поддерживаются оба порядка байт |
| `NG_LO.ROM` | Таблица Y zoom, 64 КБ; необязательна, иначе генерируется |
| `TOC.BIN` | Таблица дорожек от конвертера |
| `DATA.ISO` | Дорожка данных от конвертера |
| `TRK02.NGA`, … | Все аудиодорожки, созданные конвертером |

BIOS и игры в архив не входят. Самозагрузочный CDI собирается отдельно
имеющимся у вас инструментом подготовки дисков Dreamcast. Вместо старого
`ssrpg.elf` используйте `ngcd-dc.elf` или новый `1ST_READ.BIN`.

## Управление

| Dreamcast | Neo Geo CD / действие |
| --- | --- |
| D-pad | Направления |
| A / B / X / Y | A / B / C / D |
| Start | Start |
| L | Select |
| R на первом геймпаде | PVR ↔ программная отрисовка |
| Start + A + B + X + Y на первом геймпаде | Выход |

Второй геймпад управляет вторым игроком. Имя файла VMU `NGCDBAK`, размер
данных и идентификатор приложения в заголовке сохранены от r13, чтобы
старые сохранения оставались совместимыми. Backup RAM общая для всех игр.

## Проверка на ПК

KallistiOS не нужен. Нужны GNU Make, C-компилятор и Python 3 для тестов:

```sh
make -j4 host tools
make test
```

`make test` проверяет конвертер на искусственных образах и запускает
120 кадров с короткой синтетической программой 68000. Проверяются запись
палитры, включение видео, точные пиксели PPM и формат/тишина WAV.
BIOS и данные коммерческой игры для этих проверок не используются.

Запуск с вашим BIOS и подготовленным диском:

```sh
mkdir -p captures
./build/host/ngcd_host NEOCD.BIN - disc 3600 60 captures '120:S,240:a'
```

Аргументы: BIOS, zoom ROM или `-`, папка диска, число кадров, интервал
выгрузки изображения (`0` отключает), существующая папка результата,
необязательный сценарий нажатий. Кадры в сценарии отсчитываются с нуля;
каждое нажатие держится 8 кадров. Клавиши: `U D L R a b c d S s`.
Выход: `f000060.ppm`, … и `audio.wav`. Этот стенд не является оконным
эмулятором и не проверяет PVR, FAME/RAZE, VMU или дисковый привод Dreamcast.

`HOST_CC`, `HOST_CFLAGS`, `HOST_CPPFLAGS`, `HOST_LDFLAGS` позволяют настроить
нативную сборку независимо от переменных KOS.

## Структура

| Каталог | Содержимое |
| --- | --- |
| `src/core` | Neo Geo CD: память, CD, DMA, таймеры, видео, YM2610 |
| `src/dreamcast` | Главный цикл KOS, PVR, VMU, CD-аудио, адаптеры FAME/RAZE |
| `src/host` | Консольный стенд ПК и адаптеры Musashi/superzazu |
| `third_party` | FAME, RAZE, Musashi, superzazu Z80 |
| `tools/ngcdconv` | Исходник конвертера, Windows EXE, отдельная сборка |
| `mk` | Раздельные правила Dreamcast и ПК |
| `tests` | Синтетические интеграционные проверки |
| `docs` | Описание переноса и унаследованных ограничений |

## Статус

Это выделение r13 в самостоятельный проект, без изменения алгоритмов
эмуляции, таймингов, графики, аудио и VMU. Изменены пути, названия,
макросы фронтенда и организация сборки.

При подготовке архива проверены нативная сборка, конвертер и синтетический
прогон. Сборка SH4, запуск в Flycast и на Dreamcast здесь не выполнялись.
Утверждения исходного README о запуске SSRPG и Samurai Shodown 2 относятся
к r13; новая проверка этих игр при выделении проекта не проводилась.

См. [известные ограничения](docs/KNOWN_ISSUES.md),
[состав переноса](docs/EXTRACTION.md) и [происхождение кода](THIRD_PARTY.md).
