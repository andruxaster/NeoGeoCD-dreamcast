# Проверка выделения 0.1.0

Проверено 10 октября 2026 года в Linux с GNU Make, GCC и Python 3.

- Собраны ПК-стенд и нативный конвертер. Предупреждения компилятора
  касались неиспользуемых переменных в унаследованном Musashi.
- `make test` прошёл: однофайловый/многофайловый BIN, дополнительные индексы
  данных, INDEX 00, полезные данные секторов, структура NGA; 120 кадров
  синтетической программы 68000, ожидаемое изображение и стерео WAV.
- Для той же программы PPM на кадрах 60 и 120 и полный WAV побайтно
  совпали с результатом ПК-стенда исходного r13.
- 33 файла ядра, CPU-библиотек и конвертера побайтно совпали с исходником.
  В число не включены файлы адаптеров с обновлёнными include/именами
  и `ngcd.h` с изменённым вводным комментарием.
- Все локальные include прикладного кода разрешаются внутри проекта.
- Проверены командные графы Make для debug/release и создания BIN
  с пустым заменителем Makefile.rules. Это проверка путей и флагов,
  а не компиляция или линковка с настоящим KallistiOS.

Не выполнялись: SH4-сборка, тесты FAME/RAZE на SH4, Flycast, реальная
Dreamcast, PVR, VMU и запуск коммерческих игр. Готовые ELF/BIN не приложены.
