# Унаследованные ограничения r13

Перенос в NGCD-DC 0.1.0 сохраняет поведение исходника. Эти пункты не
исправлялись в рамках выделения проекта.

## Сохранения на VMU

`src/dreamcast/machine_ngcd.c`, `backup_poll()`: эталон `saved_backup`
обновляется до результата фоновой записи. При отсутствующей VMU, ошибке
записи или создания потока те же данные не ставятся на повторную запись
до следующего изменения backup RAM. При выходе нет принудительной записи
последних изменений и ожидания потока сохранения. Время ожидания стабильных
данных — примерно 2–3 секунды; это не гарантия успешной записи.

## Конвертер

- Предназначен для BINARY `MODE1/2352` + `AUDIO`.
- `MODE1/2048` явно отвергается. Другие типы дорожек/FILE не проверяются
  достаточно строго; WAVE/MP3 и MODE2 использовать не следует.
- `INDEX 00` поддерживается, самостоятельная директива `PREGAP` игнорируется.
- При ошибке/коротком чтении сектора исходный конвертер подставляет нули;
  обработка ошибок записи также неполная.
- Конвертер допускает 256 записей индексов, загрузчик Dreamcast — 200.

## Видео и совместимость

- Программный и аппаратный рендеры используют итоговое состояние кадра;
  видеорегистры не фиксируются для каждой строки. Растровые эффекты
  с изменениями посреди кадра могут отображаться неправильно.
- PVR масштабирует тайлы текстурированными прямоугольниками; выбор пикселей
  уменьшенных спрайтов может отличаться от программного рендера.
- Основной цикл Dreamcast рассчитан на 59,94 Гц. Это не универсальный
  планировщик для всех режимов видеовыхода.
- Перечень поддерживаемых игр не установлен. Наличие общего ядра Neo Geo CD
  не означает гарантированную совместимость со всей библиотекой.

## Диагностический стенд

ПК-стенд унаследован как инструмент разработчика: неполная проверка размеров
BIOS/TOC/NGA, нет удобного интерфейса и автоматического создания папки вывода.
Передавайте корректные файлы и заранее создавайте каталог результата.
Некоторые экспериментальные условные ветки (`CSIM`, `NGCD_DEBUG`) ссылались
на внешние средства разработки, отсутствующие в r13; стандартная сборка
NGCD-DC их не включает.
