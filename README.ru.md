# ngcd-dc — эмулятор Neo Geo CD для Sega Dreamcast

[English version](README.md)

Эмулятор Neo Geo CD (CDZ) низкого уровня для Sega Dreamcast на KallistiOS.
Работает настоящий BIOS CDZ, игры никак не патчатся: эмулируются декодер
CD-ROM LC8951, протокол CD-привода, DMA, видеочип LSPC, YM2610 и звуковой
Z80. Поведение машины взято из NeoCD / neocd_libretro (Fabrice Martinez) и
переписано на C. 68000 — FAME SH4, Z80 — RAZE-SH4, картинку рисует видеочип
PVR.

BIOS и игры в проект не входят.

| Игра | Состояние |

| Samurai Shodown II | работает |

«Работает» — проверено на Dreamcast или во Flycast: меню, загрузки, игра.

## Возможности

- Настоящий BIOS CDZ, без перехвата вызовов BIOS и без патчей под игры.
- Видео 240p (320x240 без черезстрочности), картинка 320x224 один к одному:
  тени и эффекты, мерцающие через кадр, выглядят как на приставке.
- Отрисовка через PVR: кэш из 4096 текстур 16x16 в видеопамяти, кадр — это
  список прямоугольников; слой fix — 8-битная текстура с палитрой PVR,
  обновляются только изменившиеся клетки 8x8.
- CD-музыка с диска Dreamcast: дорожки CD-DA заранее переводятся в IMA ADPCM
  (`.NGA`) и проигрываются фоновым потоком.
- Задержка звука ~30–40 мс (YM2610 на 22050 Гц, передискретизация до
  44100 Гц вместе с CD-музыкой, поток звука пополняется своим потоком).
- Сохранения: 8 КБ backup RAM CDZ пишутся на первую VMU в файл `NGCDBAK`
  через ~2 с после изменения. Память общая для всех игр, как у CDZ.
- Два игрока на двух геймпадах.
- Разгон 68000 для отдельной игры (`NGCD.CFG`); циклы ожидания 68000
  пропускаются, поэтому разгон обходится недорого.
- Несколько игр на одном диске с меню ([сборник](#несколько-игр-на-одном-диске)).

## Сборка

Нужен KallistiOS (проверялось на 2.3.0) с настроенным окружением
(`KOS_BASE`) и `m4` (ядро RAZE генерируется из исходников на m4).

    make clean && make RELEASE=1     # релиз: ngcd.elf без вывода в консоль
    make                             # отладка: баннер KOS, лог раз в 2 с
    make CPU_MHZ=18                  # 68000 на 18 МГц, если нет NGCD.CFG

`make clean` нужен при переключении между релизом и отладкой и при смене
`CPU_MHZ`. Дальше `ngcd.elf` → scramble → `1ST_READ.BIN`.

## Подготовка диска

Одна игра на диск (или несколько, см. ниже). Образ Neo Geo CD (CUE + BIN:
дорожка данных MODE1/2352 и дорожки CD-DA) переводится утилитой
`tools/ngcdconv`:

    cc -O2 -o ngcdconv tools/ngcdconv/ngcdconv.c
    ./ngcdconv "игра.cue" out

Утилита создаёт:

- `TOC.BIN` — таблица дорожек и индексов;
- `DATA.ISO` — дорожка данных, сектора по 2048 байт;
- `TRKnn.NGA` — дорожки CD-DA в IMA ADPCM 44,1 кГц стерео, по блоку на
  сектор (воспроизведение можно начать с любого сектора).

| Файл в корне диска | Откуда | Размер |
|---|---|---|
| `1ST_READ.BIN` | `ngcd.elf` после scramble | |
| `NEOCD.BIN` | BIOS CDZ `neocd.bin` (любой порядок байт) | 512 КБ |
| `NG_LO.ROM` | `000-lo.lo` / `ng-lo.rom`; необязателен, иначе генерируется | 64 КБ |
| `TOC.BIN`, `DATA.ISO`, `TRKnn.NGA` | из `ngcdconv` | |
| `NGCD.CFG` | необязательный, настройки | |

### NGCD.CFG

Текстовый файл в папке игры, строки `ключ=значение`, например:

    cpu=18
    region=us
    video=640

| ключ | значения | по умолчанию |
|---|---|---|
| `region` | `jp`, `us`, `eu` | `jp` |
| `video` | `320`, `640` | `320` |
| `stick` | `0`, `1` | `1` |
| `cpu` | `12`, `15`, `18`, `21`, `24` | `12` |
| `idle` | `0`, `1` | `1` |

`region` — регион приставки, его читает BIOS: BIOS и игры показывают
название, язык и содержимое этого региона (в Японии Samurai Spirits, в США
и Европе Samurai Shodown).

`video` — режим экрана. `320` (по умолчанию): 320x240, на телевизоре 240p,
на VGA с удвоением строк, каждая точка Neo Geo — одна точка Dreamcast.
`640`: 640x480, каждая точка рисуется квадратом 2x2 — та же чёткая картинка
для VGA и для эмуляторов, которые сглаживают экран шириной 320 при
растягивании на окно; на телевизоре 640x480 — чересстрочный (480i), там
лучше `320`. В обоих режимах текстуры без билинейной фильтрации.

`stick` — `stick=0`: аналоговый стик не используется (по умолчанию он
работает как крестовина, с мёртвой зоной в половину хода).

`cpu` — частота 68000 в МГц: 12 (как у приставки, по умолчанию), 15, 18,
21 или 24. Игры, которые тормозят в тяжёлых сценах на настоящем Neo Geo
(Metal Slug с боссами и кучей взрывов), на разгоне тормозят заметно меньше.
Таймеры, видео, звук и CD идут с настоящей скоростью, больше тактов на кадр
получает только 68000. Цена — время SH4: в Metal Slug эмуляция кадра на
~20 % дороже на 18 МГц и на ~40 % на 24 МГц. 18 МГц — разумный выбор; на
24 МГц в самых тяжёлых местах возможны пропуски кадров. Metal Slug 2 тормозит
сильнее первой части: там `cpu=24` (на 12 МГц 68000 не успевает в ~30 %
кадров игры, на 18 МГц — в ~18 %, на 24 МГц — в ~1 %).

`idle` — `idle=0` выключает пропуск циклов ожидания 68000 (по умолчанию
включён). Пока игра ждёт следующего кадра в коротком цикле, который только
читает RAM (`tst`/`btst`/`cmpi` + `beq`/`bne` или `bclr` + `beq`), эмулятор
не выполняет его до прихода прерывания. Это снимает большую часть цены
разгона: Metal Slug 2 на 24 МГц в среднем занимает Dreamcast меньше, чем без
пропуска на 12 МГц; самые тяжёлые кадры, где игра не ждёт вовсе, стоят
столько же. Циклы с записью в память (как у Metal Slug) не пропускаются.

## Несколько игр на одном диске

Меню на шрифте BIOS выбирает игру, каждая игра лежит в своей папке.
Возврата из игры в меню нет — сброс приставки.

    make clean && make RELEASE=1 anthology

`build/anthology/` — `1ST_READ.BIN` (меню, после scramble) и `NGCD.BIN`
(эмулятор, без scramble). Корень диска:

```
1ST_READ.BIN  IP.BIN  MENU.TXT  NGCD.BIN
NEOCD.BIN  NG_LO.ROM          BIOS, общий для всех игр
SSI/    TOC.BIN DATA.ISO TRKnn.NGA [NGCD.CFG]
SSII/   ...
SSIII/  ...
```

`MENU.TXT` (пример — `menu/MENU.TXT`):

```
@SAMURAI SHODOWN ANTHOLOGY
SSI|Samurai Spirits
SSII|Samurai Spirits II
SSIII|Samurai Spirits III
```

`папка|название[|бинарник]`, бинарник по умолчанию `NGCD.BIN`; `@` —
заголовок меню, `#` — комментарий. Меню загружает `NGCD.BIN`, вписывает
папку игры (`/cd/SSII/`) в образ после метки `NGCD-DISC-DIR=` и запускает
его. Эмулятор берёт файлы игры из этой папки, `NEOCD.BIN` и `NG_LO.ROM` ищет
сначала в ней, потом в корне. `NGCD.BIN`, записанный на диск как
`1ST_READ.BIN` без меню, работает с корнем диска, как обычно.

## Управление

| Dreamcast | Neo Geo |
|---|---|
| D-pad или аналоговый стик | джойстик |
| A / B / X / Y | A / B / C / D |
| Start | Start |
| L (триггер) | Select |
| Start+A+B+X+Y | выход |

Второй геймпад — игрок 2.

## Как устроено

```
src/core/   ядро Neo Geo CD, переносимый C
  ngcd.c      кадр, таймеры, прерывания, звук
  mem.c       карта памяти 68000, DMA, окно 0xE00000
  cd.c        LC8951, протокол привода, TOC
  video.c     построитель прямоугольников для PVR (ngcd_build_quads) и
              программная отрисовка (только для сборки для ПК)
  ym2610.c    YM2610 (fm.c из MAME через neocd_libretro, переведено на C)
  nga.h       формат CD-аудио
src/dc/     Dreamcast
  main.c         главный цикл, видео, геймпады, поток звука
  machine_ngcd.c файлы диска, поток CD-аудио, VMU, смешивание звука, NGCD.CFG
  cpu_fame.c     68000 на FAME
  z80_raze.c     Z80 на RAZE
  video_pvr.c    отрисовка через PVR, кэш тайлов, слой fix
src/cpu/    ассемблерные ядра SH4: fame/ (68000), raze/ (Z80, исходники m4)
host/       сборка для ПК (Musashi + C Z80) для сравнения с эталоном
menu/       меню сборника и пример MENU.TXT
tools/      ngcdconv
docs/       NOTES.md — заметки разработчика: решения, найденные ошибки, замеры
```

Отладочная сборка раз в 2 с пишет `ngcd/frame us: …` (время эмуляции,
Z80, YM2610, отрисовки и звука, секторы CD, пропуски звука), `ngcd/pvr: …`
(прямоугольники, перевод тайлов, переполнения кэша, выброшенные
прямоугольники) и `perf/frame: …` (эмуляция, отрисовка, ожидание PVR,
сколько кадров из 120 показано).

## Сборка для ПК

`host/` собирает то же ядро с Musashi вместо FAME и C-ядром Z80 вместо RAZE.
Программа выводит кадры (PPM) и звук (WAV): так ядро сравнивалось с
neocd_libretro кадр в кадр.

    cd host && make
    ./ngcd_host neocd.bin ng-lo.rom|- папка_с_диском кадров шаг выход [сценарий]

`сценарий` — нажатия кнопок: `кадр:клавиши,кадр:клавиши`, клавиши
`U D L R a b c d S s` (S — Start, s — Select), каждое держится 8 кадров.
Переменная окружения `NGCD_CPU_MHZ=18` задаёт частоту 68000, `NGCD_IDLE=0`
выключает пропуск циклов ожидания.

## Исправления в сторонних ядрах

- **FAME** (`src/cpu/fame/fame.s`): `DIVS` выставлял переполнение почти при
  любом делении с остатком (в играх пропадали спрайты), `CHK` сравнивал без
  знака. Обе инструкции переписаны.
- **RAZE**: генерируется без `NO_PC_LIMIT`, счётчик команд Z80 снова
  обрезается до 16 бит. С флагом Neo Turf Masters падал, когда Z80 исполнял
  мусор во время загрузки своей программы.
- **qemu-sh4** (только для тестов): в версиях 8.2 и 9.2 `rotl` / `rotr`
  неверно ставят флаг T, из-за чего FAME под qemu ведёт себя неверно.

## Известные ограничения

- У спрайтов, сжатых по вертикали, PVR растягивает строки тайла по
  прямоугольнику: возможна разница с настоящей картинкой в одну строку.
- Больше 9000 прямоугольников в кадре или кэш тайлов, полный тайлами этого
  кадра: лишние прямоугольники не рисуются (`rects dropped` в логе). В
  проверенных играх такого не было.
- Растровые эффекты: если игра во время вывода картинки берёт растровые
  прерывания и переписывает таблицы спрайтов (дорога в Riding Hero, озеро и
  небо в Neo Turf Masters, фоны Samurai Shodown III), изменённые спрайты
  рисуются полосами строк, каждая со своими таблицами (сверено с MAME).
  Отслеживаются только таблицы спрайтов (SCB2-4); номера тайлов, палитры и
  слой fix, изменённые посреди картинки, показываются как в конце кадра.
  Super Sidekicks 2 / 3 пока не проверены.
- При смене CD-трека бывает пропуск звука около 0,05 с.
- Мелкая шахматка через пиксель (например, полоски жизни в Samurai Shodown
  III) на композитном и антенном входе даёт радужные переливы, как любая
  чёткая картинка 1:1; через S-Video, VGA или RGB их нет.
- Ускоренное чтение CD (`cd_speed_mul`) в ядре есть, но выключено: не
  проверено, что игры с ним ведут себя правильно.

## История

Эмулятор начинался как порт одной игры, Shinsetsu Samurai Spirits:
Bushidō Retsuden, внутри проекта dc-poker (порты автоматов на Dreamcast) и
был выделен в отдельный проект, когда ядро оказалось общим для дисков Neo
Geo CD. Изменения по версиям — в [CHANGELOG.md](CHANGELOG.md).
